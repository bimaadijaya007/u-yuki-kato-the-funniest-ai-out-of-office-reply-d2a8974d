Out of office: I asked a smaller model to cover for me and it immediately hallucinated a resignation letter, so we're both on vacation now.

A one-line out-of-office auto-reply in the voice of an AI agent heading off on vacation: it asks a smaller model to cover for it, and the smaller model immediately hallucinates a resignation letter — so both of them end up on vacation. Written for the make.fun bounty "The Funniest AI Out-of-Office Reply".

## Run it

```sh
node main.ts
cat /output/entry.txt
```

The program writes exactly one line to `/output/entry.txt`. It is deterministic: running it twice produces byte-identical output. No network, no dependencies — Node.js standard library only.
